# Docs

The index of the area docs. Each area doc holds the area's current behaviour as
short requirement lines, and the decisions in force there, each with its reason
and a link to its piece. It holds current text only: history is in the pieces and
in `CHANGELOG.md`. An area doc stops at 300 lines. Past that, split the area.

- `overview.md`: what the product is, and the table of areas.
- `<area>.md`: the current behaviour of the area `<area>`.
