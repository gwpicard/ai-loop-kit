## Working with this project

Ask the coding agent to read `AGENTS.md` before making changes. The project's
current shape is recorded in `masterplan.md`, its remaining work in this
project's issues, and its history in `CHANGELOG.md`. Each finished piece first
writes its entry to its own file in `changes/`, and merging the piece folds it
into `CHANGELOG.md`.

## What the agent will and will not do

This project is built with AI Build Kit. Where the agent recognises a risk, it
tells you who is exposed and what would normally prevent it, and then it does
what you decide, including work it advised against. Anything you accepted that
way is written into `masterplan.md` with the date, so the decision stays visible
to whoever reads this next.

It flags what it can recognise and will miss things. It is not a substitute for
a professional developer, and the kit itself is provided as is, with no
warranty.
