# AI Loop Kit v1: design inputs

This folder keeps the inputs to the AI Loop Kit v1 design. They are saved here
before AI Build Kit is removed from this repository, so nothing exists only on
one computer or only online.

Issue and pull request numbers in these files were replaced with words that
name the thing.

| File | What it is |
|---|---|
| `decisions-2026-10-05.md` | The maintainer's decisions of 5 October 2026. This file is the source of truth for decisions. Where another file disagrees, this file wins. |
| `design.md` | A snapshot of the live design document, exported as Markdown. The live document is at <https://claude.ai/artifact/FZwf7EWnuG5ZH94RyW7XCF>. Its diagrams are only in the live document. |
| `inventory.md` | Every capability of AI Build Kit and of the v1 plan, with where each one lives and what v1 does with it. |
| `settled-decisions-earlier-plan.md` | The settled decisions of the earlier v1 build plan. Some are replaced by the decisions of 5 October 2026. |
| `removal-plan.md` | The plan for removing AI Build Kit from this repository, stage by stage. |
| `build-plan.md` | The plan for building v1, piece by piece, from the borrowed code to a working core. |
| `drafts/` | The research reports written for the redesign: agentic loops, gates and determinism, the records model, a red team review, skill principles, an audit of the current skills, and spec-driven tools. It also holds the two issue drafts, `issue-core-docs.md` and `issue-walk-away.md`. They are drafts and are not updated. |

Some drafts name `brief-common.md`. It is not included here, because it was a working brief and not a report.
